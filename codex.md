# Project Overview

Static landing page project.

Tech stack:
- HTML
- CSS
- Vanilla JavaScript

Project structure:
- index.html — main page
- main.css — global styles
- animations-lite.css — animations
- animations-lite.js — animation logic
- script/config.js — config
- script/configurator.js — configurator logic
- script/contact-form.js — contact form logic

Coding rules:
- Keep code simple and readable
- Do not overengineer
- Preserve existing functionality
- Prefer clean spacing and visual hierarchy
- Mobile responsiveness is important
- Avoid unnecessary dependencies
- Keep vanilla JS approach

  Animation rules:
- Existing animation files may be reused if useful
- AI may improve or replace animations if necessary
- Prefer subtle modern animations
- Avoid excessive motion
- Keep animations smooth and premium

Critical implementation restrictions:

This project is NOT React, Next.js or Tailwind.

Do NOT:
- use React
- use JSX/TSX
- use Tailwind CSS
- use npm UI libraries
- use Framer Motion
- use component frameworks
- use build tools
- use package installations

Implementation must remain:
- plain HTML
- plain CSS
- vanilla JavaScript

Design inspiration from skills is allowed.
Framework-specific implementation is forbidden.

Animations must use:
- CSS animations
- CSS transitions
- lightweight vanilla JS only

All redesign work must adapt to the existing static architecture.
